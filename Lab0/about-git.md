\# Lab0 — ответы на вопросы о Git



\## 1. Чем ветка отличается от копии папки с проектом?



Ветка — это указатель на коммит внутри одного репозитория, переключение мгновенное, история общая.

Копия папки — это физическое дублирование файлов, история не связана.



\## 2. Что произойдёт с историей, если удалить папку проекта, но сохранить `.git`?



История сохранится полностью, потому что все коммиты лежат в `.git`.

Рабочие файлы можно восстановить командой `git checkout -- .`.



\## 3. Зачем нужен Pull Request, если можно коммитить сразу в `main`?



PR позволяет провести ревью, обсудить изменения и запустить автопроверки до слияния.

Прямые коммиты в `main` лишают команду контроля качества.
